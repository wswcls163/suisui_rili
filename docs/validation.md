# 第一版实现与验证记录

日期：2026-09-08。应用在 `mobile/`，旧 `demo/` 继续保留。

## 已实现

- 七列阳历 / 农历月历、月切换、年月日滚轮跳转、回到今天、选中日期事项列表。
- 常见节日、南北小年、二十四节气和三个历史纪念日强调标注，同日多项完整展示；传统节日逐年换算、闰月不重复，除夕和节气动态计算，生日标记仍保留。
- 生日簿、详情、未来三次生日、新建、编辑和确认删除。首次使用为空。
- 时光记新建、完整列表、详情、编辑和确认删除；时光记仅在对应标签展示，不与日历和生日簿内容重复；支持“记录天数”和“每年纪念”两种展示，开始日、逐日更新、周年、下一次纪念日及未来开始倒计时均自动计算。
- 首页独立日期计算：输入任意 1901—2100 年有效日期后立即显示距北京时间今天的精确自然日数和近似年数；过去、今天和未来文案明确，无效日期就地提示，关闭即丢弃且不写入存储或同步。
- 各处统一生日标题，兼容仅填姓名或已带“生日”后缀的记录，避免重复追加；存储与编辑保留原始输入。
- 一人一条记录支持只过农历、只过阳历、两个都过；独立输入和预览、阳历固定月日、同日合并、平年 2 月 29 日提前到 28 日。
- 原始农历月日和闰月标记持久保存；闰月缺失回退、小月三十提前至二十九，同一农历年只提醒一次。
- 真实北京时间下的当天节日、节气、纪念日和全部生日提醒；同日内容在首页卡片与系统通知中合并，选日和翻月不改变今天，前台跨午夜、恢复前台、返回首页和 CRUD 后刷新。
- 手机 SQLite、电脑 IndexedDB 仓库，读写错误提示、输入保留与重试、事务和更高数据版本保护；v4 迁移保留旧生日并增加时光记录，v5 迁移增加展示方式并将旧记录默认设为“记录天数”。
- 邮箱密码注册、登录、邮箱验证回调、找回密码、保持会话、退出和注销入口；未配置云端时继续本地使用。
- 按访客和账号隔离的本地数据、离线写入队列、首次合并、完整拉取、版本冲突处理、退避重试，以及 Supabase 表、RLS、幂等 RPC 和注销 Edge Function。
- 电脑宽屏与手机宽度布局，共用同一业务逻辑；配置同一 Supabase 项目后使用同一账号同步。
