# 第一版实现与验证记录

日期：2026-09-04。应用在 `mobile/`，旧 `demo/` 继续保留。

## 已实现

- 七列阳历 / 农历月历、月切换、年月跳转、回到今天、选中日期事项列表。
- 生日簿、详情、未来三次生日、新建、编辑和确认删除。首次使用为空。
- 原始农历月日和闰月标记持久保存；闰月缺失回退、小月三十提前至二十九，同一农历年只提醒一次。
- 真实北京时间下的当天全部生日提醒，选日和翻月不改变今天；前台跨午夜、恢复前台、返回首页和 CRUD 后刷新。
- 手机 SQLite、电脑 IndexedDB 仓库，读写错误提示、输入保留与重试、事务和更高数据版本保护。
- 电脑宽屏与手机宽度布局，共用同一业务逻辑；数据暂不跨设备同步。

## 电脑浏览器实际操作

在 `http://localhost:8081` 验证了空状态、新增当天生日、提醒和月历同步、刷新后数据保留、详情未来三次换算、编辑到次日后移除当天提醒、生日簿剩余天数、确认删除及清空测试记录。

检查了 390 像素手机宽度和 1280 像素电脑宽度，没有页面横向溢出；日期选择器可滚动选择三十天。浏览器验收未出现控制台错误。测试记录已删除，交付预览保持空数据。浏览器数据只属于当前浏览器和当前访问地址。
