# 岁岁日历 · 账号登录产品设计

版本：V0.2｜范围：邮箱密码登录与跨设备数据同步｜状态：客户端与云端迁移已实现，待接入实际 Supabase 项目验收

本文档梳理账号功能的产品方向和主要范围。现有生日、累计日、农历与月历功能保持不变；账号用于保存和恢复数据，不应成为使用核心日历功能的门槛。下文“事项数据”包含生日和累计日。

## 1. 产品目标

- 用户更换手机、重新安装应用或在电脑上登录后，可以恢复自己的事项数据。
- 手机与电脑使用同一个账号时，生日和累计日的新增、修改和删除能够自动同步。
- 网络不可用时仍能查看和编辑已有数据，恢复网络后继续同步。
- 登录流程保持简单，第一阶段只提供邮箱与密码，不增加短信、微信或其他第三方登录。

## 2. 使用原则

应用采用“本地可用、登录后同步”的方式：

- **未登录**：可以正常使用日历、生日和累计日管理，数据只保存在当前设备。
- **已登录**：本地数据继续保留，同时自动同步到该账号的云端空间。
- **离线状态**：继续使用本地数据；联网后自动提交离线期间的改动。
- **账号隔离**：每个账号只能看到自己的事项数据，不在不同账号之间共享。

首次登录时，如果当前设备已有本地生日，应用先说明这些数据将加入账号，再由用户选择合并。云端和本机都存在数据时不得静默覆盖或删除；内容完全相同的生日自动跳过，其余记录都保留。若同一条生日在不同设备被同时修改，则同时展示两份内容并由用户选择。

## 3. 主要功能

### 注册

- 输入邮箱、密码和确认密码创建账号。
- 发送验证邮件，用户完成邮箱验证后即可正常使用云端同步。
- 明确提示邮箱格式、密码要求、邮箱已注册等错误，不清空用户已经填写的内容。

### 登录

- 使用邮箱和密码登录，支持显示或隐藏密码。
- 登录成功后保持登录状态，日常打开应用不需要反复输入密码。
- 登录失败时区分邮箱或密码错误、网络不可用和服务暂时不可用，并提供可执行的下一步操作。

### 找回密码

- 用户输入注册邮箱，接收密码重置邮件。
- 从邮件完成新密码设置后，可以在原设备或新设备重新登录。
- 为避免泄露账号是否存在，找回入口使用统一的结果提示。

### 账号与会话

- 在设置页查看当前登录邮箱和同步状态。
- 支持退出登录；退出后清除该账号留在设备上的生日缓存，避免共用设备泄露数据。
- 支持注销账号。注销前明确说明云端生日数据将永久删除，并进行二次确认。
- 第一阶段通过找回密码流程完成密码修改，暂不单独设计修改邮箱流程。

### 数据同步

- 登录后自动拉取云端数据；登录前保存在本机的生日由用户在账号页确认后合并和上传。
- 新增、编辑和删除生日后尽快同步，并显示“已同步”“同步中”“离线”或“同步失败”等简洁状态。
- 同一账号在多台设备修改数据时，以不丢失生日记录为优先；遇到无法自动判断的冲突时保留数据并提示用户处理。
- 退出登录、注销账号或切换设备前，如仍有未同步修改，需要给出明确提示。

## 4. 主要流程

### 新用户

打开应用 → 可先本地使用 → 进入账号页 → 注册 → 验证邮箱 → 本地生日加入账号 → 完成首次同步。

### 已有账号用户

打开应用 → 登录 → 自动下载云端生日 → 继续查看或编辑 → 修改自动同步到其他已登录设备。

### 忘记密码

登录页选择“忘记密码” → 填写邮箱 → 查收重置邮件 → 设置新密码 → 返回应用登录。

## 5. 界面方向

- 登录和注册使用独立的简洁页面，延续当前温暖、易读的视觉风格。
- 首页不长期占用空间展示账号信息；同步正常时保持安静，只在离线、失败或需要用户处理时提示。
- 设置页集中放置登录邮箱、同步状态、退出登录和注销账号。
- 未登录用户可以在设置页看到“登录后可跨设备保存”的入口，但不使用频繁弹窗打断日历操作。

## 6. 第一阶段不做

- 手机号、短信验证码、微信、Apple、Google 等登录方式。
- 家庭共享、多人共同维护生日或账号权限管理。
- 修改登录邮箱、多邮箱绑定和复杂的账号申诉流程。
- 生日以外的文件、照片或通讯录云同步。
- Windows 独立安装包；电脑端先继续使用浏览器页面验证账号和同步功能。

## 7. 技术方向

客户端继续使用 Expo + React Native，并保留 SQLite 本地数据；账号认证与云端数据优先采用 Supabase Auth + PostgreSQL。手机应用和电脑浏览器共用同一套账号与数据，具体实现见[账号登录技术方案](account-login-technical-design.md)。

## 8. 验收重点

- 注册、验证邮箱、登录、保持登录、找回密码、退出登录和注销账号流程完整。
- 未登录时现有本地功能不受影响；首次登录不会丢失本机已有生日。
- 同一账号在手机与电脑新增、编辑或删除生日及累计日后，另一端能够得到一致结果。
- 断网时可以继续使用，恢复网络后自动同步且不产生无故重复记录。
- 不同账号的数据严格隔离，密码不以明文保存或传输。
- 同步失败、账号错误和网络异常都有清楚提示，不以成功状态掩盖失败。

账号与云同步应在正式公开发布安装包前完成；开发期间仍可生成仅供真机验证的测试安装包。
