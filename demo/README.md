# 岁岁日历 · 界面 Demo

这是验证界面与操作流程的前端原型，不是真实生日提醒服务。

## 可以体验

- 首页七列月历，同时显示阳历、农历与生日标记；支持翻月、选日期和回到今天。
- 选中日期 → 日期事项区的“＋” → 选择“生日” → 自动带入农历日期 → 填写称呼并保存。
- 事项类型预留普通日程、纪念日、倒数日；这些类型标注“后续开放”，当前不可创建。
- 今日生日提醒独立于所选日期，翻看历史或未来月份不会改变模拟今天。
- “生日簿”标签保留按下次生日排序的亲友列表、编辑和添加入口。
- 新建生日自动带入所选日期的农历月、日和闰月标记，仍可手动修改，并预览相对模拟今天的下次生日。
- 查看生日详情及后续年份的日期，编辑和确认删除。
- 五种场景：生日当天、今天没有生日、闰月生日、小月三十、首次使用。
- 场景切换保留当前页面改动；重置需确认。刷新页面恢复示例数据。

## 范围说明

- 亲友均为模拟记录，演示日期固定，不跟随真实今天，也不计时跨午夜。
- 不连接后端、数据库或通知服务，不申请通知权限，不使用浏览器持久存储。
- 农历月份采用 2025—2028 年的有限演示历表，来自 lunar-python 1.4.4 的月份信息；前端按已经确认的规则演示日期调整。这不是完整生产历法引擎。
- 月历可选阳历范围为 2025-01-29 至 2029-02-12，边界月份中超出范围的日期禁用；月份导航也有限制。
- 下一阶段需确定运行平台、时区、正式历法库、数据存储和真实日期刷新机制，再进行生产级历法验证。

## 本地运行

需要 Node.js 22.13 或以上版本，推荐当前受支持的 LTS 版本。

```sh
npm install
npm run dev
```

打开终端显示的本地地址。

## 验证

```sh
npm test
npm run typecheck
npm run lint
npm run build
```

自动测试覆盖日期边界、逐日预填往返、跨月跨年浏览、月历标记、选中日期与今日提醒隔离、类型限制、模拟增删改、场景切换及 WebMCP 工具的单元契约。未进行浏览器点击、截图或视觉测试；WebMCP 未在原生支持上下文中验证，不宣称其浏览器集成已通过。

Lint 检查业务代码与项目配置，排除未经修改的脚手架组件目录和配套 `use-mobile` hook；类型检查仍覆盖整个项目。

## 结构

- `app/`：页面入口、布局与主题样式。
- `components/birthday/`：主界面编排、月历、生日簿、新建与详情编辑面板。
- `lib/birthday/`：模拟状态、有限历表计算、月历事件与类型目录、可选 WebMCP 接口。
- `components/ui/`：脚手架提供的界面基础组件。
- `tests/`：可重复执行的自动测试。

本原型使用 Sites 脚手架，构建为静态页面。正式应用技术选型仍可调整。
